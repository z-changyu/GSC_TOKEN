### 3.1 full-prompt 精度 27.3% **低于随机猜测**

150 个样本平均 2.75 个选项 → 随机猜测基线约 **36.4%**。full-prompt 精度 27.3% 说明管线本身在丢失信息，而不是"方法还不够好"。
**任何在此基线上测出的"proposed > random"都不足以支撑论文主张。**

从 `outputs/pilot/results.csv` 抽样看到的直接证据：

| 症状 | 实例 |
|---|---|
| 接收端输出格式失控 | 预测 "The capital of Georgia is Tbilisi."（整句）而非选项 "Atlanta"；预测 "b. c. d." |
| 发射端元指令泄漏 | semantic_prompt 生成了 *"Generate a concise semantic prompt in the target language that asks for the correct statement about seeds..."* —— VLM 复述了指令而非产出语义描述 |
| 语义 prompt 丢失关键证据 | "What is the capital of North Carolina?" —— 无选项、无视觉证据，接收端无从作答 |
| 预测被 `max_new_tokens=16` 截断 | 预测长度中位数 30.5 字符、最长 117 字符，说明大量输出被截断或跑偏 |
| 答案抽取过严 | `run_pilot.py::canonical_prediction` 要求 `stripped[1:2] in (".", ")", ":")` 才认作选项字母，"B. armored catfish" 能过，但 "The capital of..." 这类直接落到 raw text，几乎必然失配 |

根因判断（待逐项验证）：接收端 **Qwen3-1.7B 完全看不到图像**，所有视觉证据必须靠发射端的语义 prompt 传递；而发射端 prompt 工程与解码参数（96 new tokens、无格式约束）不足以保证这一点。

## 4. ⚠️ 代码与论文公式的偏差（必须逐条修正）

> **状态：4.1–4.5 已于 2026-08-28 全部修正并补上单测，详见 [第 10.1 节](#101-已完成的修复)。**
> 以下为修正前的比对记录，保留用于审计。

以下逐条比对 `GSC_TVT_theory_reinforced_EN.pdf` 公式与 `src/pragmatic/` 实现。**第 4.1–4.5 条是实质错误，会直接影响实验结论的有效性。**

### 4.1 `A_i`（式 10）—— 归一化分母错误 + 层聚合策略错误

- **论文**：
  `A_i = (1/(L_c·H)) · Σ_l Σ_h [ 1/max{1, N_k−i} ] · Σ_{j=i+1}^{N_k} α^{(l,h)}_{j,i}`
- **代码**（`src/pragmatic/attention_score.py`）：
  ```python
  tensor = tensor[-1] if self.layer_reduction == "last" else tensor.mean(0)  # 默认 last
  ...
  values = tensor.mean(dim=(0, 1))
  ```
- **偏差**：
  1. 对 query 维 `j` 求均值时**分母是全体 N 个 query，而不是 `N_k − i` 个 j > i 的 query**。因果掩码使 `j ≤ i` 的项恒为 0，因此靠后的 token（i 大）被系统性低估。
  2. 默认 `layer_reduction="last"` **只取最后一层**，而论文要求对全部 `L_c` 个 masked 层求平均。
- **修正**：按 `i` 逐位置除以 `max{1, N−i}`，层聚合默认改为对 masked decoder 层集合求平均，`layer_reduction` 保留为可配消融项。

### 4.2 `G_i`（式 14）—— 缺失 `‖e_i − e_mask‖₂` 因子

- **论文**：`G_i = ‖∂L_T/∂e_i‖₂ · ‖e_i − e_mask‖₂`
- **代码**（`src/pragmatic/gradient_score.py`）：
  ```python
  return ScoreResult(torch.linalg.vector_norm(grad, ord=2, dim=-1), ...)
  ```
- **偏差**：只算了梯度范数，**少了删除幅度 `‖e_i − e_mask‖₂`**。论文式 (12)(13) 的 Taylor 展开里这个因子是删除扰动 `Δe_i` 的模长，是式 (14) 的组成部分。
- **修正**：显式传入 `e_mask`（可用 tokenizer 的 mask token embedding，或按论文"未传输 token 替换为 mask embedding"的定义构造），乘上该因子。

### 4.3 `M_ij`（式 16）—— 对称化违反因果假设

- **论文**：`M_ij = (1/(L_c·H)) Σ_l Σ_h α^{(l,h)}_{j,i}` for `i < j`，否则 `0`。M **严格上三角**，且论文原文明确：
  > *"No bidirectional average or symmetric storage is used."*
- **代码**（`src/pragmatic/coupling.py`）：
  ```python
  directed = tensor.mean(0)
  return (directed + directed.transpose(0, 1)) / 2
  ```
- **偏差**：做了 `(M + Mᵀ)/2` 的**双向对称平均**，人为制造了**反向（j → i，即未来→过去）的注意力权重**，直接违背第 II-C 节的因果性假设。这会让式 (63) 的 `κ_k` 与式 (41) 的 `d_{M,k}` 计算全部失真。
- **修正**：取下三角（key 维）投影为严格上三角 `M_ij (i<j) = mean_{l,h} α^{(l,h)}_{j,i}`，其余置 0；不要用对称化。

### 4.4 上下文耦合效用（式 17）—— 耦合项缺失 `u'_i` 因子

- **论文**：`F_T(T) = Σ_{i∈T} u'_i + β · Σ_{i<j, i,j∈T} M_ij · u'_i · u'_j`
- **代码**（`src/pragmatic/utility.py::context_aware_utility`）：
  ```python
  return base + beta * (off_diagonal @ base)   # = u'_i + β Σ_j M_ij u'_j
  ```
- **偏差**：耦合项少乘了 `u'_i`。论文式 (56)(57) 的插入增益 `Δ_j⁺ = u'_j (1 + β Σ M_ji u'_i)` 也印证了耦合项是**二次型**（两个 u' 相乘），代码退化成了线性型。
- **修正**：`base + beta * base * (off_diagonal @ base)`（逐元素乘）。
- 注：`run_pilot.py` 中 `coupling_enabled=False`，所以该错误尚未污染已产出的 pilot 结果，但一旦启用耦合（论文核心卖点）就会出错。

### 4.5 `G_i` 的损失函数 `L_T`（式 2）—— 用错了目标

- **论文**：`L_m(P) = −Σ_{t=1}^{T_y} log p_{θ_m}(y*_{k,t} | y*_{k,<t}, I_k, Q_k, P)`
  即：**在图像 I、问题 Q、prompt P 的条件下，真实答案序列 y\* 的自回归 NLL**。
- **代码**（`run_pilot.py`）：
  ```python
  gradient_scorer = GradientScorer("teacher_forced_self_nll", "generated_semantic_prompt_full_sequence")
  ...
  score_output = transmitter(inputs_embeds=embeddings, attention_mask=mask, labels=ids, ...)
  gradient = gradient_scorer.score(score_output.loss, embeddings, ...)
  ```
- **偏差**：用的是**语义 prompt 文本自身的 teacher-forced 自 NLL**，既没有图像，也没有问题和答案。它只是一个"能跑通反向传播"的能力验证（脚本里标了 `capability_only`），**不是论文式 (2) 定义的 `L_T`**。
- **修正**：按式 (2) 构造 —— 输入 = `[视觉 token] + [Q] + [P] + [y*]`，只对 `y*` 部分计 loss，对 `P` 的 token embedding 求梯度。这也是 `docs/open_questions.md` 里挂了很久的头号待决问题。

### 4.6 次要偏差

| 位置 | 论文 | 代码 | 说明 |
|---|---|---|---|
| 式 (11) `S_i` | 分母含 `+ε₀`，余弦分母含 `+ε₀` | `clamp_min(1e-12)` + `F.cosine_similarity` 默认 `eps=1e-8` | ε₀ 未作为显式超参暴露 |
| 式 (10)(16) 的 `L_c` | "masked decoder layers" 的集合需显式指定 | Qwen3-VL-2B 有 28 层 attention，代码未区分 | 需定义并冻结层集合 |
| 视觉 token | A/S/G 定义在 prompt token 上 | pilot 中 prompt 是纯文本第二次前向，已规避 | 若改在整条多模态序列上打分需重新对齐 |

### 11.9 实验 3 语义代理验证（正式结果）

配置：60 样本（折 0 测试集，无泄漏）× 全部 token 单删，权重用 `(0.25, 0, 0.75)`，`σ_e²=0.01`，ε_out=0.05，耦合缓存。

**单 token 小扰动（式 (14)/(27) 成立的区间）**
- 代理尺度标定 `|true_single| ≈ α·|proxy|` 得 **α = 0.917**——单 token 处代理幅度与实测 NLL 增量同量级，**尺度是标定的**。
- **70%（fraction 0.697）的 token 被删除后 NLL 上升**——确实起作用。
- 但代理与 `|true_single|` 的 **秩相关仅 Spearman 0.22**（Pearson 0.28）——代理对 token 重要性的排序较噪。

**集合级大扰动（式 (27) 作为紧等式不成立）**
- 删除最关键的 m 个 token 时，真实 NLL 增量远小于 `Σ u'_i`：代理是**保守上界**，尺度比约 `true/proxy ≈ 0.17`。
- 因 `G_i = ‖∂L/∂e_i‖·‖e_i−e_mask‖` 是 L2 范数乘积（恒非负、方向盲），真实有向导数还要乘 `cos θ`，故代理系统性高估。实验 6 的最优性界也依赖此保守性。
- 集合级 Spearman = −0.18，余项对式 (27) 基 `{√m, m, m^{3/2}}` 的覆盖率仅 0.45 → **式 (27) 的"余项有界"在集合级不能按字面验证**，应改写为"代理是退化的保守上界"或只在单 token 级成立。

**对论文的写法建议**：式 (27) 的论证应在单 token 一阶（α≈0.92 已验证）层面陈述，并明确代理是方向盲的保守上界；不要声称集合级余项紧界。

| SNR | K | θ→0（bang-bang） | θ≈0.1–0.5（峰） | θ→∞（等 split） | jain_bw（θ→0→∞） |
|---|---|---|---|---|---|
| 15 | 4 | acc 0.133 / jain 0.25 | **acc 0.550** / jain 1.0 | acc 0.500 / jain 1.0 | 0.25 → 1.0 |
| 15 | 10 | acc 0.033 | **acc 0.383** | acc 0.333 | 0.10 → 1.0 |

1. **G_i 是必需且主导的分量**（移除即崩溃）——强支撑论文梯度代理 + Taylor/误差界主线。
2. **差异化保护**有真实收益（single_level 退化）。
3. **A/S/耦合在 G 之上增益很小**——"三维融合"在实践中被 G 主导；论文关于三维融合的贡献声明应降调，或强调 A/S 通过 S 定义 G 的方向而间接作用（见论文待补充清单 J1）。
4. 标定与精修各有边际正收益，与理论预期一致。

### 11.11.1 消融的四信道鲁棒性（Rician / frequency-selective，闭合 R9）

**消融排序的信道无关性**——三种信道下最差项始终是同一组：

| 消融 | 跨信道表现 |
|---|---|
| no_gradient | 三种信道各 SNR 几乎都最差（瑞利/莱斯 0dB=0.018，频选 0dB=0.164）；仅 10–15dB 预算宽松时追上，低/中 SNR 崩溃 |
